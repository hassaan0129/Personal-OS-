# Feature planning workflow

1. Restate the user outcome, constraints, and non-goals.
2. Derive testable acceptance criteria, including failure, loading, empty, permission, and recovery states.
3. Map affected UI, API, data model, background jobs, analytics, security, tests, docs, and deployment.
4. Identify backward-compatibility and migration requirements.
5. Split implementation into small independently verifiable steps.
6. Define exact validation commands and manual checks.
7. Record unresolved decisions instead of hiding them.
8. Do not start editing until the plan is coherent and risks are named.
